# 📚 Complete English Grammar — Bengali Medium

### সম্পূর্ণ ইংরেজি ব্যাকরণ — বাংলা মাধ্যমে

A comprehensive, interactive single-file HTML website covering English Grammar from beginner to advanced level. All explanations in Bengali, all English terms labeled clearly.

---

## 🎯 Target Audience

| Audience | Level |
|----------|-------|
| 🧒 Class 5 Children | Foundation |
| 📚 SSC/HSC Students | Intermediate |
| 🎓 University Students | Advanced |
| 📋 BCS Aspirants | Exam-focused |
| 🌍 IELTS Candidates | Test prep |

---

## ✨ Features

- **Single HTML File** — No dependencies except Google Fonts
- **Dark Theme** — Easy on the eyes (#0d0d0d background)
- **Sidebar Navigation** — Sticky, collapsible on mobile
- **Real-time Search** — Filter across all topics instantly
- **Progress Tracker** — localStorage-based, shows % per chapter
- **Print-to-PDF** — Clean print CSS for offline study
- **Multi-level Tabs** — Each section has:
  - 🧒 শিশু বোঝার অংশ (Kids explanation)
  - 🎓 বিশ্ববিদ্যালয় স্তর (University level)
  - 📋 BCS প্রস্তুতি (BCS preparation)
  - 🌍 IELTS টিপস (IELTS tips)
- **MCQ Quiz Mode** — Instant feedback with score tracker
- **Bookmark System** — Save any paragraph for later
- **Dark/Light Mode Toggle**
- **Back-to-Top Button**

| # | Chapter | Topics Covered |
