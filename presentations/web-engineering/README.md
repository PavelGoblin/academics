# Web Engineering — Cookies & Sessions

An interactive, animated, and child-friendly HTML presentation about **Cookies & Sessions** in web development.

## Features

- 3D animated cookie with mouse parallax
- Particle system background with mouse interaction
- 3D flip cards comparing Cookie vs Session
- Interactive device logout table
- Real cookie-based theme switcher (Dark / Light / White / Argentina Vibes)
- Remember Me token visualizer
- Flowcharts, analogies, and quiz with detailed feedback
- বাংলা deep-dive Q&A section for presentation prep

## Topics Covered

1. Visual Difference: Cookie vs Session
2. How Facebook & Google Manage Sessions
3. How "Remember Me" Works
